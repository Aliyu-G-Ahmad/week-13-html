Phase 2 week 1 (wk13) exercise on Html: structure and meaning Uplifthub Bootcamp 2026

A three-page personal site built with zero CSS — no <style> block, no external stylesheet, no style attribute anywhere. proper landmarks, one <h1> per page, no skipped heading levels, a fully labelled and keyboard-navigable contact form, and a shared <nav> linking everything together.

Repo: https://github.com/Aliyu-G-Ahmad/week-13-html

Pages
File	Purpose
index.html	Who I am, what I do, links to the other two pages
about.html	about Me, a skills list, projects
contact.html	A real contact form — 7 fields, validation, fieldset/legend, mailto: and GitHub links
profile.svg	Hand-built SVG used as the page's image asset
